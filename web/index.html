Devices

Discovered live from host sysfs every poll -- nothing about a raw device is persisted. A device is only ever granted to a container at creation time (see the "Container" create action's own Devices section, where a mapping's name works exactly like a raw device id); there is no separate attach step for an already-running container.

Named mappings

Persisted, operator-named bindings (ADR-0048) -- an exact mapping pins to one specific bus location; a vendor/model mapping follows a device across USB ports. Only named devices appear under Devices in the tree.

PKI: Intermediate CA

Optional second CA tier -- once bootstrapped, every future certificate issuance is signed by it instead of the root, and delivered certs carry the full chain. Requires the root CA above.

PKI: Reset CA chain

Wipes and regenerates the root (and intermediate, if bootstrapped), reissuing every currently-tracked leaf cert under the new chain. Destructive -- every previously-issued cert stops verifying against the new root the moment this completes. Leaves empty to default each name to Kanxeo Root/Intermediate CA - <domain_suffix>.
