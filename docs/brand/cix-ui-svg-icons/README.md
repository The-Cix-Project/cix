# Cix UI SVG Icon Set

Canonical brand source: the approved CIX Brand Guidelines supplied on 25 Aug 2026.

## Brand
- `brand/cix-mark.svg` — canonical B5.1.E mark, traced directly from the approved guide; uses `currentColor`.
- `brand/cix-mark-black.svg` — one-colour black.
- `brand/cix-mark-source-white.svg` — Source White (`#F2F5FA`).
- `brand/cix-app-icon.svg` — Raw Iron (`#0A0E14`) app tile with Source White mark.

The logo is **not** redrawn on the 24×24 icon grid and is not geometrically altered to match the UI icons.

## UI icons
102 individual SVGs in `icons/`. All use a 24×24 viewBox, 1.75 stroke, rounded caps/joins and `currentColor`.

Categories: navigation, resources, observability, actions, status/security and general UI. See `manifest.json` for the full list.
