# pkg/recipes/

60 packages, each a `<name>/<version>/recipe.sh` — real, from-source build recipes for Kanxeo's own `pkg install`. Each `recipe.sh` is a plain shell script following a strict, documented format: see [`docs/guides/writing-recipes.md`](../../docs/guides/writing-recipes.md) for the complete authoring guide, with a real worked example.

Layout (ADR-0107): `<pkg_name>/<pkg_version>/recipe.sh`, where both the directory names and the recipe's own internal `pkg_name=`/`pkg_version=` fields must agree exactly. A package can have more than one published version side by side (e.g. `curl/8.20.0/recipe.sh` and `curl/8.21.0/recipe.sh`) — recipe versions are immutable once published, never overwritten in place; fixing a mistake means publishing a new version. Uploaded to a running daemon via `POST /pkg/recipes` or `kanxeoctl pkg recipe add --name=NAME --file=PATH` — these files are the *source* for a fresh deployment's initial catalog, never read directly off disk by `kanxeod` itself or baked into the installer ISO (see ADR-0040).
